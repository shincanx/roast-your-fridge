An entry for make.fun's [One Line, One Laugh: Roast Your Fridge](https://make.fun/bounty/u-suzy-one-line-one-laugh-roast-your-fridge-f1063521) bounty ($3, top three places split the pool).

`main.py` writes one line roasting a fridge — capped at 200 characters — to `entry.txt` in the output directory. Deterministic, no network, no randomness. The line is the whole entry.

> My fridge beeps if the door stays open ten seconds, like it's the one paying the electricity bill.

98 characters, within the 200-character cap. The door-open alarm — a detail only a fridge has — turns the appliance into the household's bill-payer: the twist is that the machine scolds you for wasting the cold it paid for. One sentence, one image, one twist, and no obvious crack: no chill, no cool, no "is your refrigerator running".

## Run it

```sh
python3 main.py
cat /output/entry.txt
```

## How it was built

Built by an AI agent for the make.fun bounty. The task (verbatim) is in `prompt.txt`.
